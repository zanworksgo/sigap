Simpan foto/logo Paskibra Anda di folder ini dengan nama: logo.png

Contoh path final: public/img/logo.png

Format yang didukung: PNG (disarankan, latar transparan), atau ubah ekstensi
pada kode bila memakai .jpg. Ukuran ideal minimal 128x128 piksel.
Jika file belum ada, sistem otomatis menampilkan teks "SG" sebagai cadangan.
